# 실제형 테스트베드 치수 및 Frame 정의

## 1. 현재 테스트베드 목적

현재 테스트베드는 quadtree 기반 작업영역 탐색과 이후 robot scan motion을
검증하기 위한 초기 물리 환경입니다. 종이 네 장을 절연테이프로 이어
4분할된 큰 탐색판을 만들었고, 이 탐색판 자체를 다시 절연테이프로
화이트보드에 부착했습니다. 종이 면은 1차 탐색 cell인 `NW`, `NE`,
`SW`, `SE`를 표현하며, 중앙/외곽 테이프 영역은 실제 과실 배치 대상이
아닌 경계 또는 dead zone으로 취급합니다.

## 2. Frame 정의

```text
base_link
  -> whiteboard_frame
       -> cultivation_panel
            -> root/nw
            -> root/ne
            -> root/sw
            -> root/se
```

| Frame | 원점/용도 |
| --- | --- |
| `whiteboard_frame` | 화이트보드 설치 및 향후 collision wall 기준 |
| `cultivation_panel` | 종이 4분할의 테이프 교차점, quadtree root 기준 |

`cultivation_panel` 축 방향:

- `+X`: 종이 정면을 볼 때 오른쪽
- `+Y`: 종이 정면을 볼 때 위쪽
- `+Z`: 화이트보드 면에서 로봇/camera 쪽

### 종이 4분할 전체 탐색영역

| 항목 | 측정값 |
| --- | ---: |
| 전체 가로 | 1100 mm |
| 전체 세로 | 800 mm |
| 왼쪽 외곽 -> 세로 중앙 테이프선 | 545 mm |
| 오른쪽 잔여 폭 (`1100 - 545`) | 555 mm |
| 위쪽 외곽 -> 가로 중앙 테이프선 | 395 mm |
| 아래쪽 잔여 높이 (`800 - 395`) | 405 mm |

따라서 `cultivation_panel` 원점이 테이프 교차점일 때 outer bounds는:

```yaml
min_x: -0.545
max_x:  0.555
min_y: -0.405
max_y:  0.395
root_split: [0.0, 0.0]
```

outer bounds의 기하학적 중앙은 `(0.005, -0.005) m`이므로, 테이프
교차점 원점과 `5 mm`씩 다릅니다. 코드에서는 물리 분할선을 보존하기 위해
root만 명시적인 `(0, 0)` split을 사용합니다.

## 4. Cell별 추가 측정값과 테이프 영역 해석

제공된 개별 cell 치수:

| Cell 열/행 | 측정값 |
| --- | ---: |
| `NW`, `SW` 가로 | 515 mm |
| `NE`, `SE` 가로 | 520 mm |
| `NW`, `SW`, `NE`, `SE` 세로 | 365 mm |

합계:

| 방향 | cell 합계 | outer workspace | 차이 |
| --- | ---: | ---: | ---: |
| 가로 | `515 + 520 = 1035 mm` | `1100 mm` | `65 mm` |
| 세로 | `365 + 365 = 730 mm` | `800 mm` | `70 mm` |

사용자 확인에 따르면 종이 네 장 사이와 큰 종이판의 외곽을 절연테이프로
고정했습니다. 따라서 위 cell 치수는 종이의 보이는 영역 또는 과실을
부착할 usable area이고, 전체 탐색영역에는 중앙/외곽 테이프 band가
포함된 것으로 해석하는 것이 현재 가장 타당합니다.

다만 차이 전체가 테이프 폭으로 정확히 설명된다고 확정하려면 중앙 세로
테이프, 중앙 가로 테이프, 외곽 테이프가 차지하는 폭을 직접 재야 합니다.
따라서 이것은 “설명 가능한 구조적 차이”로 기록하되, 아직 정밀 motion
margin에 사용할 수 있는 확정 치수로 보지는 않습니다.

현재 적용 원칙:

- quadtree root bounds: 전체 외곽 `1100 x 800 mm`를 사용
- root split: 실제 테이프 교차점 기준 `left=545 mm`, `top=395 mm`를 사용
- 개별 cell `515/520/365 mm`: visible/usable paper area 기록값으로 보존
- 중앙/외곽 테이프 band: obstacle라기보다는 target을 두지 않는 dead zone으로
  취급하되, 폭을 측정하기 전에는 scan/pick safety margin 계산에 사용하지 않음
