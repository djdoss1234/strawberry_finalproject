# 공개용 시각자료 폴더

이 폴더에는 GitHub, 포트폴리오, 발표 자료에서 공개할 대표 캡처와 짧은
시연 자료만 저장합니다.

원본 이미지, 전체 영상, rosbag은 `artifacts/`에 보관하고 Git에는
올리지 않습니다. 자세한 규칙은 `docs/visual_asset_guide.md`를 참고합니다.

폴더 구분:

```text
architecture/  전체 시스템 구조도와 대표 graph
exploration/   quadtree, scan pose, workspace 시각화
motion/        robot motion, planner, collision/retry 비교
tray/          tray localization, slot, place 결과
integration/   VLA 또는 module 통합 graph/demo
results/       최종 성과표와 대표 시연 자료
```
