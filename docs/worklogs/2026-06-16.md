# 작업 일지 — 2026-06-16

## 목표

gripper feedback 기반 파지 판정을 position-only 기준으로 보완하고, SafeGrasp calibration 결과를 반영한다.

---

## 진행 내용

- 기존 current 기반 SafeGrasp는 얇은 줄기에서 반복성이 부족했다.
- gripper가 목표 close position까지 도달했는지, 중간에서 멈췄는지를 이용하는 position-only 판정을 추가했다.
- `GRASP_EMPTY_POSITION_THRESHOLD`를 685에서 700으로 올려 빈 파지 판정 기준을 조정했다.
- SafeGrasp calibration trial 결과를 통해 얇은 줄기/모루줄기에서 전류 기반 판정이 항상 안정적이지 않음을 확인했다.

---

## 결론

- 전류값은 물체 접촉 가능성을 알려주는 보조 지표로 유용하다.
- 하지만 모형 딸기 줄기처럼 얇고 유연한 대상에서는 position-based 판정과 사람 라벨을 함께 사용해야 한다.
- 현재는 완전 자동 성공률 주장보다 `자동 후보 판정 + 사람 최종 라벨` 구조가 더 안전하다.
