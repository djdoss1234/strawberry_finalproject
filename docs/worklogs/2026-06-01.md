## 토픽 구조 (업데이트)

```
YOLO detector
  └─→ /strawberry/detection/pick_pose  →  scan_executor_node (버퍼)

scan_executor_node
  ├─→ /dsr01/curobo/pick_pose          →  curobo_planner_node (순차 트리거)
  └─→ /strawberry/scan/status          →  harvest_session_logger, 모니터링

curobo_planner_node
  ├─→ /dsr01/curobo/pick_complete      →  scan_executor_node (완료 신호)
  └─→ /strawberry/vla/request          →  VLA 팀 노드 (파지 실패 이관)
```
