## Quadtree의 역할 범위

본인이 구현할 범위:

- workspace frame 기준 재배 영역 분할
- cell 상태 관리
- 관찰해야 할 다음 영역 선택
- cell별 camera scan pose 생성
- motion planner/executor에 scan target 전달
- 수확 성공/실패 결과를 cell 상태에 반영

팀원/VLA와 분리할 범위:

- 딸기가 실제로 수확 가능한지 semantic 판단
- 가림/복잡도/위험 해석
- `PICK`, `SKIP`, `REOBSERVE` 제안

정리하면:

```text
Quadtree: 어디를 관찰하고 다시 방문할지 관리
VLA: 관찰 영역 안에서 무엇을 수확할지 판단
Motion: 실제로 이동하고 안전하게 수확 가능한지 검증/실행
```
