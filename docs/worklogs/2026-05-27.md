## 오늘 목표

1. RViz에서 `cultivation_panel` 기준 네 cell marker를 표시합니다.
2. camera overview의 `NW/NE/SW/SE` 라벨과 RViz label 방향을 비교합니다.
3. `root/nw -> root/ne` next-cell 상태 전환을 화면으로 기록합니다.
4. 이후 `cultivation_panel -> base_link` transform을 정의할 측정 절차를 정합니다.

## 현재 확인한 기준

```text
cultivation_panel origin = 종이 중앙 테이프 교차점
+X = 보드를 정면에서 볼 때 오른쪽
+Y = 보드를 정면에서 볼 때 위쪽

root/nw = (-X, +Y)
root/ne = (+X, +Y)
root/sw = (-X, -Y)
root/se = (+X, -Y)
```

`src/strawberry_motion/exploration/quadtree_map.py`의 quadrant 생성 순서와
`docs/testbed_setup.md`의 축 정의가 위 기준에서 일치함을 확인했습니다.

## 오늘 추가하는 도구와 기록

- `rviz/workspace_exploration.rviz`: cell/label/next marker 캡처용 화면 구성
- `launch/workspace_rviz.launch.py`: marker node와 RViz를 동시에 실행
- `RUN-20260527-001`: RViz와 실제 workspace 방향 대응 검증 절차/결과 기록
- 최초 실행 시 RViz `Global Status: No tf data` 발생:
  marker가 사용하는 `cultivation_panel` frame을 제공하는 TF publisher가
  없었던 것이 원인이므로, standalone visualization용 identity TF
  (`workspace_visualization_world -> cultivation_panel`)를 launch에 추가
- TF 보완 후 축/grid만 보이고 cell marker가 표시되지 않는 증상을 확인:
  node는 `/strawberry/exploration/workspace_cells`를 publish하고 있었지만,
  RViz는 기본 `/visualization_marker_array`를 구독 중이었음
- 원인은 `.rviz`의 MarkerArray topic property를 `Marker Topic`으로
  작성한 설정 오류이며, ROS 2 RViz 형식인 `Topic`으로 수정
