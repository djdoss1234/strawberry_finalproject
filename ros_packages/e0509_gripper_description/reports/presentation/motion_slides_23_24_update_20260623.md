## Slide 23 수정안 - 성공 사례 분석

현재 슬라이드 제목:

```text
MOTION: 성공 사례 분석
```

제목은 유지 가능. 부제만 넣는다면:

```text
정상 노출 딸기에서 연속 pick-place 가능성 확인
```

### 본문 복붙안

```text
주변 잎/줄기 간섭이 적고 줄기 방향이 명확한 딸기에서는
현재 모션 구조로 연속 수확 및 place까지 가능함을 확인

성공 조건
- 타겟과 실제 줄기 위치가 명확함
- 주변 잎/줄기 간섭이 적음
- 그리퍼 접근 방향과 줄기 방향이 크게 어긋나지 않음

대표 성과
- 정상 노출 딸기 3개 연속 pick-place sequence 완료
- 격자 tray place 3/3 완료
- 접근-파지 구간 36.4초 → 15.1초
- 약 58.6% 단축

시간 단축은 모션 형태 자체보다
후보 탐색, IK 계산, 불필요한 대기시간을 줄인 최적화의 결과
```

### 23페이지 그래프 설명 문구

지금 들어간 그래프가 "한 번의 3개 성공 run" 기준이라면 아래처럼 말하면 안전하다.

```text
그래프는 정상 노출 딸기 3개를 연속 수확한 대표 run의 시간 분해 결과입니다.
전체 통계라기보다, 현재 모션이 정상 조건에서 pick-place까지 연결될 수 있음을 보여주는 예시입니다.
```

주의:

```text
전체 task 평균 약 61.7초
```

이 문구는 지금 최신 10회 반복 로그 기준과 섞이면 헷갈릴 수 있다. 최신 반복 실험에서는
`pick sequence 평균 34.2초/개`, `3개 run 평균 약 118초`로 정리하는 편이 더 안전하다.

슬라이드에 공간이 부족하면 `전체 task 평균 약 61.7초`는 빼고, 24페이지 반복 표에서 평균을 말한다.

## Slide 24 수정안 - 복잡한 줄기/잎 환경에서의 수확 실패 분석

현재 슬라이드 제목:

```text
MOTION: 복잡한 줄기/잎 환경에서의 수확 실패 분석
```

제목은 좋다. 다만 표 역할을 더 명확히 하려면 부제를 추가:


### 24페이지 핵심 메시지

```text
모든 후보를 동일한 모션으로 시도했을 때,
성공은 주로 줄기가 곧고 주변 장애물이 적은 딸기에 집중되었다.
반대로 잎/줄기 가림, Y자 줄기, 군집 딸기는 인식이 되어도
접근 방향·깊이·주변 간섭 문제로 실패가 많았다.
```

## Slide 24 표 배치 추천

### 추천 배치

```text
상단: 조건별 요약 표
하단: 한 줄 결론 + 개선 방향
오른쪽 또는 표 옆: 실패 케이스 사진 2~3개
```

현재 슬라이드에 사진 ①②③④가 있으니, 표는 너무 크게 만들지 말고 4행 정도로 압축하는 게 좋다.

### 표 1안 - 발표용 가장 깔끔한 버전

| 딸기 상태 | 반복 시도 결과 | 주요 실패 원인 | 개선 방향 |
|---|---|---|---|
| 줄기가 곧고 주변 간섭이 적은 딸기 | 10회 반복, 총 30개 중 27개 성공 | target과 실제 줄기 위치가 잘 맞는 경우 안정적 | 현재 모션 유지 + 반복 검증 |
| Y자/꺾인 줄기 | 빗겨 접근하거나 줄기 위쪽을 놓침 | 실제 줄기 방향을 gripper 각도에 충분히 반영하지 못함 | stem direction 기반 grasp orientation |
| 주변 줄기/딸기가 겹친 경우 | 다른 줄기와 같이 잡거나 파지 실패 | 주변 얇은 줄기/잎이 collision world에 없음 | 주변 줄기/딸기를 obstacle로 반영 |
| 잎/줄기 가림 또는 높은 위치 | 인식은 되어도 직선 진입/IK 실패 | depth/keypoint 불안정, 관절 branch 제약 | multi-view 재관찰 + 도달 가능 target 우선 |

### 표 2안 - 10회 반복 수치를 더 강조하는 버전

| 조건 | 수확 시도 | 성공 | 실패 | 해석 |
|---|---:|---:|---:|---|
| 정상 노출 / 직선 줄기 / 간섭 적음 | 30 | 27 | 3 | 현재 rule-based motion으로 가장 안정적 |
| Y자/꺾인 줄기 | 정성 반복 시도 | 대부분 실패 | - | gripper 방향이 줄기를 못 따라감 |
| 주변 줄기/딸기 군집 | 정성 반복 시도 | 일부 접근 | 다수 실패 | 다른 줄기와 동시 파지 |
| 잎/줄기 가림 / 높은 위치 | 정성 반복 시도 | 제한적 | 다수 실패 | depth/keypoint/직선 진입 불안정 |

표 2안은 숫자와 정성 분석이 섞여서 약간 어색할 수 있다. 발표 안정성은 표 1안이 더 좋다.

## 10회 반복 실험 수치 삽입 방식

PPT에 작은 박스로 넣기:

```text
정상 노출 딸기 반복 검증
- 10회 반복
- 회당 정상 딸기 3개
- 총 30개 중 27개 성공
- 성공률 90.0%
- 평균 2.7개/회 수확
```

또는 한 줄:

```text
정상 노출 조건에서는 10회 반복 기준 30개 중 27개 성공(90.0%)으로 비교적 안정적이었다.
```

주의:

```text
SW셀에서 27/30 성공
```

처럼 말하지 말고,

```text
주변 간섭이 적고 줄기가 명확한 정상 노출 조건에서 27/30 성공
```

이라고 말한다.

## 발표 스크립트 - Slide 24

```text
24페이지는 조건별 실패 분석입니다.
저희가 모든 딸기를 같은 방식으로 수확 시도했을 때,
성공은 대부분 줄기가 곧고 주변 간섭이 적은 딸기에 집중됐습니다.

정상 노출 조건에서는 10회 반복, 총 30개 중 27개를 성공해서
현재 rule-based 모션이 안정적으로 동작하는 범위를 확인했습니다.

하지만 Y자처럼 갈라진 줄기나 주변 줄기가 겹치는 경우에는
딸기 자체는 인식됐어도 그리퍼가 줄기 방향을 제대로 따라가지 못하거나,
다른 줄기와 같이 잡는 문제가 발생했습니다.

즉 실패 원인은 단순히 비전 인식 실패가 아니라,
줄기 방향, 접근 깊이, 주변 간섭, 그리고 특정 자세에서의 직선 진입 가능성 문제였습니다.
그래서 다음 단계는 실제 줄기 방향을 grasp orientation에 반영하고,
가려진 target은 다른 각도에서 다시 보고,
주변 줄기와 딸기를 obstacle로 반영하는 방향입니다.
```
